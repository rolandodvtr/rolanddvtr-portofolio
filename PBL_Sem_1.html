Second semester

CIM

(Computer Integrated Manufacturing)

This is a continuation of the previous semester. Connecting Scara, robot arm, and conveyor into one system. The way it works is that the ARM Robot loads the object to conveyor. Then the conveyor sorts the object based on its material. SCARA robot moves the object to the place according to the sorting result.

Wiring Diagram

this time I'm still working on the electrical part. This is a component of the components contained in this tool. This tool is controlled using two Arduinos, which are connected to each other with UART Communication.

On the conveyor, it uses a 12-volt DC motor whose speed can be controlled through the GUI. To adjust the speed, a motor driver L293D is used.

E18 - d80nk infrared sensor is used to detect the material at the starting point, also at the beginning of the conveyor. and to sort the material using a capacitive sensor.

The voltage source for all components comes from a 12v power supply.

then the voltage is reduced using a step down to match the input voltage (5v).

Installation of each scara servo pin data and robot arm on arduino input.

Mini Trainer Kit PLC

This semester I worked on the electrical part and helped in making the 3D design of the tool. We are required to make a PLC trainer kit but in a mini and compact form, with the aim of being easily carried everywhere by learners such as vocational school students or people who want to learn the basics of PLC.

Based on the Outseal Mega V2 PLC which has 25 input pins and 27 output pins.

This PLC has own software, named “Outseal Studio” .

so besides learning about electricity, here I also started learning to make PLC ladder programs.

each pin on the PLC is connected to the Female Header that has been soldered to the PCB, using an awg 20 cable as a connector

fourth semester

PVDF filtration with UV-C

This semester I am working on a project that is making a 3D design of a water filtration device based on PVDF filters and UV - C lamps equipped with solar panels. My team wanted a finished design of the device they wanted to work on.

This tool works by sucking water with a pump, then flowing to the PVDF filtration and after that to the water tank that has been provided in which there is a UV-C lamp to further purify the water, at the bottom of the tank there is a selenoid valve opening and closing the flow which is controlled using a microcontroller.

Using DC input by utilizing a battery supplied by a solar panel. Or it can also use AC 220 voltage on the port that has been provided.

This semester, I focused on learning how to use SolidWorks software to create 3D designs. The process began with determining the scale and size of each tool component. By utilizing information about sizes and dimensions from the internet and marketplaces, I was able to create each design.

fifth semester

Scada Monitoring Sistem

This semester, my team and I were assigned to create a monitoring and warning system for a mini process fabrication station. During the project, I was tasked with connecting users to machines and creating a system on the machines that could receive and send information back to users.

Overall, this is the workflow of this project. Starting from the user side to the monitoring dashboard display. The monitoring dashboard can receive feedback on the system.

As the control center, I use a Mitsubishi FX5CPU PLC, which supports several necessary ports, one of which is the RS485 port. So, for communication with

the embedded system (esp32), I chose the Modbus RTU communication protocol. However, I still use the LAN port because it must be on the same IP.

esp32 is used as a bridge between user commands and PLC. In the program code, only need to call the special address available on the PLC software (example below) to transmit commands from the website and vice versa. This special address also provides information to the web dashboard regarding the processes occurring on the machine.

The ESP32 and PLC cannot communicate directly. Because they work differently, a converter is needed to connect the two. Using the “XY-017 TTL to RS485 Converter Module.”

This is a setting in the PLC software (GX works3), by changing the host station number (from 0 to 1) to change its role from Master to Slave.

This is a special address provided by the PLC ( for example M0 = 8192 ). So, just write this address in the program code on the esp32 to send/receive information from the machine.
